Cache All Teams (Prep Tool)
Warms the historical-odds cache for every team's completed season in one pass, so later on you can check any team's ATS trends in any matchup for free instead of clicking through games one at a time. This is the same data the per-game "Load ATS/O-U Trends" button pulls — just done once, up front, for the whole league. Cost is real (see estimate below) but one-time — anything already cached is skipped automatically on future runs.
League Underdog Trends by Week
Checks how underdogs actually did against the spread in each week of a season — the real, computed answer to things like "do dogs cover more in Week 1 than Week 3," using your actual historical odds data instead of outside research.
This Season So Far
Grades every Elo prediction made for completed games in the current season — the live, ongoing answer to "is this thing actually right this year," updated as more weeks finish.
Model Backtest
Replays a season week by week. For each week, the model is built only from games completed before that week (walk-forward — no peeking ahead), predicts every game, then grades itself against the real results. Free — pure ESPN data, no API credits used.
🔬 Box Score Probe (diagnostic)
Inspects the player-level box score for one completed game, so position-split defensive stats (receptions allowed to RBs vs WRs vs TEs) can be built on verified field names instead of guesses. Shows every stat category, its column keys, and a sample player with their position. Free — ESPN data only. Temporary tool; it comes out once the real build is done.
ATS Backtest — Model vs Real Spread
The straight-up backtest above doesn't touch odds at all. This one does: for every game, checks whether the team the Elo model favored (straight-up) would have covered the real posted spread that game. Uses your historical odds data — a full CFB season is expensive (130+ teams), so testing a specific week range instead is much cheaper. If you already ran "Cache All Teams," any weeks already cached come back free.
Testing 2026? Games from before this season's Week 1 don't exist yet — set Through Week to whatever week has actually been played so far, not the full season.
Game Line Edge Finder
Compares the Elo model's win probability against the market's implied probability on every game this week, and flags meaningful gaps. Needs your odds API connected to see market lines.
Sets which book's exact numbers show on the Schedule tab and get used when you tap-to-bet. The edge scanner below still checks all books regardless of this setting, since it's meant to compare across books.
Blends a per-play efficiency model (yards/play, 3rd down %, red zone %, turnovers, plus defensive disruption stats) into the Elo rating. Default is off — Elo's 73.4% straight-up accuracy is verified, this is not yet. Use the ATS Backtest to test weights against real games before trusting it. Honest limitation: ESPN doesn't publish yards-allowed, so the defensive side is built from sacks/takeaways/TFLs rather than true yards-allowed efficiency.
🛡️ Opponent Defense Data
ESPN doesn't publish yards-allowed directly, so this reconstructs it from box scores — walking every completed game and summing what each defense gave up. It also splits receiving by position (RB / WR / TE), since a defense that funnels catches to backs is a completely different matchup than one that gets beaten by receivers. Free (no API credits), but slow — roughly a minute per 60 games, plus a short roster pass up front (box scores carry no position field, so player positions have to be looked up). Build it once a week; results are cached.
For the current season, set Through Week to whatever's actually been played — fetching future weeks just wastes time. CFB is far slower (many more games); NFL is the quick one.
Weekly Props Scanner
Pulls posted player prop lines for every game this week, cross-references each player's real game log, and ranks every prop by how often they've actually gone over that number. This wires together several new pieces at once — real API cost, and worth checking the first run carefully.
Find a Player
Search a team's roster, pick a player, and pull their real game log — season average, recent form, and history against a specific opponent if you enter one.
Player Prop Edge Calculator
Enter the book's line/odds. If you looked up a player above, "Use This" fills in a data-based projection and hit rate — or enter your own. The calculator shows what the book's price implies, whether your number represents an edge, and what Kelly staking suggests.
Pick 6 — This Week's Card
Enter RunYourPool's spread for each of your 6 picks. The model's implied line shows alongside so you can see where it agrees or disagrees with the pool's number — RunYourPool's lines lock Tuesday and don't move, so a gap here is often just the market having moved since, not a model insight.
This book selector is independent from your default sportsbook on the Edge tab — set it to whichever book you want RunYourPool's lines checked against.
Auto-Pick Best 6 From Pool Lines
Paste every game's spread from RunYourPool below, one per line — format like "Chiefs -3.5". The app matches each to the model's implied line, ranks every game by how far the pool's number is from the model's, and fills your 6 picks with the biggest gaps automatically. You still review and can edit before saving.
Survivor Pool — Season Planner
Straight-up wins only, no spreads. Each team can be used once per entry, so the real question isn't "who wins this week" — it's which week to spend each team. A team that's only a strong favorite once all season should be saved for exactly that week. This plans a full path for both entries and deliberately keeps them on different teams each week, so one upset can't kill both.
Assumes a tie eliminates you (standard in most pools). Planning far ahead is useful for spotting scarce weeks, but treat late-season specifics loosely — the model knows very little about Week 15 in September.
Teams Already Used
Tap a team to toggle it as used for that entry. Used teams are excluded from all future planning.
